# swamp-stack-status

[swamp](https://swamp.club) extension `@mgreten/stack-status` — fetches a PR
stack's review/CI status from GitHub and renders it as a self-contained HTML
flowchart.

📖 **Extension documentation:** [extensions/models/README.md](extensions/models/README.md)

📦 **Install:** `swamp extension pull @mgreten/stack-status`

## Repository layout

This repository is a swamp workspace (its own `.swamp.yaml` repo). The
publishable extension lives under [extensions/models/](extensions/models/).
